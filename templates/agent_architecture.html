状态设计（已实现）

一次运行 = 一个 thread_id。共享状态（TypedDict）：site、topic、current_stage、artifacts（各阶段产出，字典合并）、scores（引用概率、外链质量）、approvals（审批记录）、trajectory（轨迹，列表追加）、errors、brief_revision。并行节点不写 current_stage，避免同一超步冲突。现有 30 秒结果缓存不用于工作流（带副作用 / 待审批结果不能缓存）。

分阶段路线图

  1. 0
    保持外壳 ✔ 完成

    不推翻 Flask 界面、鉴权与现有测试。不需要 LLM 密钥。

  2. 1
    图化工作流 ✔ 完成

    LangGraph 改写 SEO 工作流：17 个节点、共享 State、SqliteSaver 检查点、interrupt 接入审批台；工具仍为示例数据。不需要 LLM 密钥。

  3. 2
    接入真实工具 下一步

    用 MCP 或官方 API 接 Google Search Console、页面抓取（实现 workflow/tools.py 的 StageTool 并 register_tool()）；Ahrefs / Semrush 有密钥后再接。一般不需要 LLM 密钥。

  4. 3
    局部接入 LLM 需密钥

    只在简报撰写、扇出子问题、外展草稿、分析叙事等需要判断的节点用模型；开放探索才用真 ReAct。

  5. 4
    记忆与评估

    接 LangMem / Store，用 LangSmith 或 Langfuse 追踪，用固定站点样例做离线评估。

  6. 5
    可选加固

    有明确收益时加简报评审循环；拆分服务时再上 A2A；登录接口加失败次数限制。

✅ 不需要密钥就能做

  • 把工作流迁到 LangGraph + checkpointer 已完成
  • 把 human_gate 改成真正的 interrupt + 审批台 已完成
  • 用规则做入口路由 已完成
  • 保留引用与外链评分公式、任务指标统计 已保留
  • 用 MCP 或官方 API 接只读数据（如 Search Console）
  • 接入运行跟踪，沿用现有鉴权与测试

🔑 必须有密钥才能做

  • 动态 think()，即真正的 ReAct
  • 内容简报与思维导图生成
  • 自然语言建议和查询扇出子问题生成
  • 外展邮件草稿、评审循环
  • LangMem 式记忆提取，以及用大模型做软路由

在没有密钥前，生成类节点不伪装成模型对话；页面上统一标注「模拟」。
