核心模式与风险优化

Orchestrator-Worker 中央编排器分解任务，分派专家，汇总结果。
适用：子任务可预测
风险：编排器瓶颈 / 单点故障
优化：限制直接下属数；加超时与重试；轨迹全量记录
Hierarchical 多层编排器。
适用：大规模分解
风险：摘要丢失细节
优化：结构化状态传递；关键字段不压缩；中间校验
Parallel Fan-out / Fan-in 独立任务并行，再汇聚。
适用：无依赖低延迟
风险：合并冲突 / 复杂聚合
优化：明确聚合规则（投票/优先级）；失败只重试单路径
Sequential Pipeline 固定顺序依赖。
适用：严格阶段
风险：早期错误传播
优化：每阶段 schema 校验；中间人工闸门；可回滚
Handoff / Blackboard 对等或共享状态。
适用：动态路由
风险：追踪困难 / 上下文丢失
优化：结构化 handoff payload；跨边界 span；全轨迹日志

系统级优化

当前 Coordinator 已支持轨迹记录。建议持续强化：

  • 跨 Agent 边界 schema 校验
  • 独立质量评分与超时熔断
  • Human-in-the-Loop 闸门（已在 SEO 工作流中实现）
  • 可观测性：完整 Thought-Action-Observation 轨迹
