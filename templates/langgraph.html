核心定位

低层编排框架由 LangChain 团队维护（MIT 许可）。将智能体建模为节点与边的有向图，共享状态在图中传递。适合长期运行、有状态的工作流。
持久执行检查点机制保存每步状态。失败后可从中断处恢复；支持时间旅行调试与人工中断（interrupt）。
当前版本2026 年 11 月约 1.2.x。支持 Python 与 JavaScript/TypeScript。LangSmith 提供追踪与评估（付费层）。

核心概念

节点（Node）执行步骤：函数、LLM 调用或完整智能体。每个节点接收当前状态并返回更新。
边（Edge）定义控制流。条件边根据状态决定下一节点。支持循环与分支。
状态（State）类型化共享对象。检查点器在每步后持久化，支持恢复与回放。
中断（Interrupt）任意节点可暂停等待人工审批，再继续执行。适合 HITL 闸门。

框架对比（2026）

LangGraph显式图 + 检查点。最高控制与持久性。适合生产级、可审计、需人工审批的流程。学习曲线较陡。
CrewAI角色 + 任务 + 船员。快速原型。适合内容与研究管道。Flows 增加事件驱动控制。
AutoGen多智能体对话。已进入维护模式。微软推荐使用 Microsoft Agent Framework（2026 年 4 月 GA）。

适用场景

推荐使用长期运行工作流、需分支与重试、人工审批闸门、故障恢复、审计追踪。
可考虑替代简单线性流程可用 CrewAI 快速原型；纯对话协作可评估 Agent Framework。
与本系统关系当前系统采用轻量顺序管道 + ReAct。若需生产级持久性与图编排，可评估引入 LangGraph 作为外层编排。

LangGraph 是 2026 年生产级智能体编排的参考架构。核心优势是检查点、HITL 中断与显式控制流。适合需要可靠性与可审计性的场景。
